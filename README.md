# Lark Fencing responsive website template

A framework-free, multi-page website rebuilt from the design references in this folder.

## Pages

- `index.html` — home and services
- `catalog.html` — filterable product collection
- `product.html` — product detail with live estimator
- `quote.html` — validated quote request form

Shared styles, scripts, and optimized project imagery live under `assets/`.

## Preview

Open `index.html` directly in a browser, or serve the folder from any static host. For example, with VS Code use **Live Server**. No build command or package installation is required.

## Production connection points

The quote form currently demonstrates client-side validation. Connect the submit handler in `assets/js/main.js` to your email, CRM, or form endpoint before launch. Replace the sample phone, email, prices, legal links, and business claims with verified production details.
